2. Überblick der Verarbeitungen

Brotzeit ist eine App für Gruppenbestellungen (z. B. Brotzeit-Bestellungen unter Freunden/Kollegen). Die App funktioniert ohne klassische Benutzerkonten/Registrierung mit Passwort — stattdessen wird jedem Gerät eine zufällige, lokal erzeugte Geräte-ID zugewiesen. Diese Datenschutzerklärung erklärt, welche Daten dabei verarbeitet werden, wofür, und wer sie außer uns zu sehen bekommt.

3. Welche Daten wir verarbeiten

3.1 Geräte-ID

Beim ersten Start der App wird eine zufällige, geräteinterne Kennung erzeugt und lokal gespeichert. Sie dient dazu, dein Gerät innerhalb einer Gruppe wiederzuerkennen (z. B. um deine eigenen Bestellungen zuzuordnen), ohne dass du dich mit Name, E-Mail oder Passwort anmelden musst.

3.2 Name, Gruppen- und Bestelldaten

Wenn du einer Gruppe beitrittst, gibst du einen frei wählbaren Namen an (muss kein echter Name sein). Zusätzlich werden folgende Daten im Rahmen der Nutzung gespeichert:

  • Name und Code der Gruppe, der du beitrittst
  • Deine Bestellungen (ausgewählte Produkte, Mengen, Preise)
  • Wer innerhalb der Gruppe als "bezahlt" markiert wurde (interne Abrechnung zwischen Gruppenmitgliedern — kein echtes Zahlungssystem, es fließt über die App kein Geld)

Diese Daten sind für alle Mitglieder derselben Gruppe sichtbar, da das der Zweck der App ist (gemeinsame Bestellungen koordinieren und abrechnen).

3.3 Push-Benachrichtigungen

Wenn du Benachrichtigungen erlaubst, wird ein Push-Token (vergeben von Firebase Cloud Messaging, einem Dienst von Google) auf unserem Server hinterlegt. Damit können wir dir Benachrichtigungen schicken, z. B. wenn eine neue Bestellrunde gestartet wird oder eine Bestellfrist naht.

3.4 Werbung (Google AdMob)

Die App zeigt Werbeanzeigen über Google AdMob an, um die kostenlose Nutzung zu ermöglichen. Dabei können folgende Daten durch Google verarbeitet werden:

  • Werbekennung deines Geräts (z. B. iOS IDFA, Android Advertising ID) — nur mit deiner Einwilligung
  • Ungefähre Standortdaten (z. B. Land/Region, zur regionalen Anzeigensteuerung)
  • Geräteinformationen (Gerätetyp, Betriebssystemversion)
  • Interaktionen mit Anzeigen (z. B. Anzeige angesehen, angeklickt)

Einwilligung: Beim ersten Start der App wird Nutzern aus der EU/dem EWR ein Einwilligungsdialog (bereitgestellt über Googles "User Messaging Platform") angezeigt. Personalisierte Werbung wird nur angezeigt, wenn du dem zustimmst. Auf iOS wird zusätzlich die Erlaubnis zum geräteübergreifenden Tracking (App-Tracking-Transparency, Apple-Vorgabe) separat abgefragt. Du kannst deine Einwilligung jederzeit über die App-Einstellungen bzw. die Datenschutzeinstellungen deines Geräts widerrufen oder anpassen.
